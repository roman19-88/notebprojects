## Функция логирования с декоратором `log`

### Что делает функция?

Функция `log` — это декоратор, который позволяет логировать успешные вызовы функции, а также ошибки, которые могут
возникнуть. Логирование может быть направлено либо в консоль, либо в файл, в зависимости от переданных аргументов.

### Как использовать?

```python
from functools import wraps

def log(filename=None):
    """Декоратор логирования"""

    def inner(func):
        @wraps(func)
        def wrapper(*args, **kwargs):

            try:
                result = func(*args, **kwargs)
            except Exception as e:
                msg = f'{func.__name__} error: {e.__class__.__name__}. Inputs: {args}, {kwargs}'
                raise e
            else:
                msg = f' {func.__name__} ok '
                return result
            finally:
                if filename is None:
                    print(msg)  # Логирование в консоль
                elif filename is not None:
                    with open(filename, 'w') as file:
                        file.write(msg + '\n')  # Логирование в файл

        return wrapper

    return inner
```
    
    
# Описание функций для чтения данных

Этот проект содержит функции для чтения данных из CSV и Excel файлов и преобразования их в формат списка словарей, где каждая строка в файле представлена отдельным словарем. Это удобно для последующей работы с данными.

## Функции

### 1. `csv_read(path_name)`
Эта функция используется для чтения данных из CSV файла.

#### Параметры:
- `path_name` (str): Путь к CSV файлу. Убедитесь, что путь правильный и файл существует.

#### Возвращаемое значение:
- Список словарей, где каждый словарь представляет одну строку из CSV файла. Ключи словаря — это имена столбцов, а значения — данные в строках.

#### Пример использования:

```python
import pandas as pd

def csv_read(path_name):
    """функция чтения csv файла"""
    df = pd.read_csv(path_name, delimiter=';')  # Используем точку с запятой как разделитель
    df_dict = df.to_dict(orient='records')  # Преобразуем DataFrame в список словарей
    return df_dict

# Пример вызова функции
data = csv_read('path/to/your/csvfile.csv')
print(data)
```

## Основные функции:

1. Загрузка транзакций:
- Пользователь может выбрать один из трех типов файлов для загрузки:
- JSON
- CSV
- XLSX

2. Фильтрация по статусу:
- Транзакции могут быть отфильтрованы по состоянию:
- EXECUTED (исполненные)
- CANCELED (отмененные)
- PENDING (ожидающие)

3. Сортировка по дате:
- Пользователь может выбрать сортировку по дате в порядке возрастания или убывания.

4. Фильтрация по валюте:
- Есть возможность выводить только рублевые транзакции.

5. Фильтрация по описанию:
- Пользователь может вводить ключевые слова для поиска в описаниях транзакций.

### Вывод информации
Программа выводит итоговый список транзакций с информацией о дате, описании, зачисленном счете и сумме операции
